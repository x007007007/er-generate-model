# Version 1: Initial Blog Schema

## Overview
This is the initial version of the blog database schema, containing only the basic User entity.

## Changes
- Created User entity with basic fields:
  - id (UUID, Primary Key)
  - username (String, Unique)
  - created_at (DateTime)
